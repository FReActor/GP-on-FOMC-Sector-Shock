Inputs: surprise_bp, vix, slope_2s10s, beta_1y, mom_20d. Generated by `python -m src.export_formulas`; do not edit by hand.

One row per GP run (10 seeds per cell). The formula predicts the sector's excess return over SPY, in percent. `R² train` is on 1999-2009 (train+val), `R² test` is out of sample on 2010-2015; both against the per-ticker train mean. *const* = the run predicts the same number for every event.

Reading caveat: gplearn's `div` is protected (returns 1 when the denominator is near 0) and surprise_bp is exactly 0 on ~9% of events, so a term like $c/\mathrm{surprise\_bp}$ is really a switch on 'no surprise'. sympy prints plain $a/b$ and can even simplify such a program to $0$; the raw gplearn program is in `gp_formulas.csv` (column `program`).
